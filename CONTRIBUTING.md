# Contributing

Contributions are welcome through **forks and pull requests only**.

## How to contribute a book

1. Fork this repository.
2. Create a branch in your fork.
3. Add the book or material to your fork.
4. Keep the filename clear and consistent.
5. Make sure the material can legally be redistributed.
6. Open a Pull Request targeting the `main` branch of this repository.
7. Wait for review before the contribution is merged.

## Rules

- Do not open Issues to submit books.
- Do not request direct write access.
- Do not add unrelated files.
- Do not add duplicates.
- Do not modify or remove existing books without a clear reason.
- Every contribution is reviewed before merge.
- The maintainer may request changes or reject a contribution.

## Recommended filename format

```text
Book Title - Author - Edition.pdf
```

If the author or edition is unknown, use the clearest accurate title available.

## Copyright

Only submit books and materials that may legally be redistributed.

By opening a Pull Request, you confirm that you have checked the redistribution rights for the submitted material.
